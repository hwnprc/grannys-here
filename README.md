# Granny's Here

> Granny's stories, right where they happened.

An ambient memory companion for people living with early-to-mid stage dementia,
built on the Vexo Open band.

Built at **VexoHacks** (AI Wearables Hackathon, Y Combinator SF) — November 14, 2026.

---

## The problem

For people with early-to-mid stage dementia, memories aren't gone — they're hard
to reach. Most memory apps are passive: you have to already know what to search
for, which is exactly the thing that has become difficult.

Family stories disappear for a second reason, too. Nothing captures the *places*
they happened in. The lake, the kitchen, the pew by the window — the places that
hold the memory are the first thing lost when someone moves into care.

## The solution

Granny wears the Vexo band and tells her stories naturally, out loud, the way she
always has. AI turns each story into a structured memory linked to a place.

When she is near that place again, the band **glows softly**. One tap plays a
gentle invitation in a calm narrator's voice — *"You used to come here with your
daughter every Sunday. Would you like to hear that story?"* — and then her own
original voice, telling it herself.

Family can open a 3D world of that place, generated by World Labs Atlas from a
handful of family photos, and revisit it together.

### Principles

- **Invite, never quiz or correct.** The band offers a story; it never tests her.
- **Family approves what can surface.** Sensitive memories never auto-trigger.
- **Transparent about listening.** A solid blue light means the mic is on.
- **Quality-of-life support, not treatment.** This does not prevent or slow
  dementia, and we never claim it does.

## How it works

```
Vexo band (mic, tap, light)
   │  Bluetooth
   ▼
capture.py ──► memories/<id>/audio.wav + transcript.txt   (Deepgram)
   │
process.py ──► OpenAI extraction ──► memory.json
           ──► ElevenLabs ─────────► intro.mp3
           ──► World Labs Atlas ───► world.mp4
   │
demo.py ──► "arrive" at a place ──► band glows amber ──► wait for tap
        ──► play intro.mp3, then audio.wav
        ──► open web/viewer.html?id=<id>
```

1. **Capture.** `capture.py` records the story from the band's mic over
   Bluetooth and transcribes it with Deepgram.
2. **Understand.** `process.py` asks OpenAI for a structured memory — people,
   place, time period, emotion, whether it's sensitive — plus a one-line spoken
   invitation and a visual scene prompt.
3. **Voice.** ElevenLabs renders the invitation in a warm narrator voice. This is
   deliberately *not* a clone of Granny: her own voice is only ever her real
   recording.
4. **Place.** World Labs Atlas turns family photos and the scene prompt into a
   navigable 3D world of the location.
5. **Return.** When she arrives, the band glows warm amber. A tap plays the
   invitation, then her story, and opens the 3D world for the family.

> **Note on location.** In the product, the phone's GPS triggers arrival. For
> this build, arrival is simulated from the keyboard (`p` = park, `k` = kitchen)
> so the demo runs entirely on a laptop.

## Setup

Requires Python 3.9+, macOS or Linux, and a Vexo Open band.

```bash
git clone https://github.com/hwnprc/grannys-here.git
cd grannys-here
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Clone the Vexo Open kit into the repo root as `vexo-open-kit/` (the URL is in
the VexoHacks kit instructions). It is reference material — it is **not
committed and never edited**, and its `docs/api.md` is the only source of truth
for band library calls.

Create a `.env` in the repo root (never committed):

```bash
# Key names for Deepgram and OpenAI come from vexo-open-kit/env.example
DEEPGRAM_API_KEY=...
OPENAI_API_KEY=...
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID=...     # a warm, calm narrator voice
WORLDLABS_API_KEY=...
```

### Using the band

- Connect only to **our own band number** — the number on the bag the band came in,
  so band 7 is `Vexo-HACK-07`. Never another team's band, and never the `42` from the
  kit's examples.
- **One program at a time** — close the Vexo dashboard tab before running Python.
- **Double-tap the band before every connect.** A blue blink means it is
  discoverable for 60 seconds.
- Most scripts accept `--sim` so you can work without the band.

## Running it

```bash
# 1. Capture a story from the band (BAND is our own band number)
python3 capture.py $BAND --id sunday-park

# ...or without the band
python3 capture.py --from-file story.wav --id sunday-park
```

```bash
# 2. Build the memory: OpenAI + ElevenLabs (+ Atlas)
python3 process.py sunday-park --location park --approve --atlas
```

```bash
# 3. Generate the 3D world (photo + scene_prompt, ~5 min, uses credits)
python3 place_to_world.py sunday-park
```

```bash
# 4. Serve the web pages from the repo root
python3 -m http.server 8000
```

```bash
# 5. Run the demo loop (p = park, k = kitchen, q = quit)
python3 demo.py $BAND
```

Then: press `p` → the band glows amber → tap it → the invitation plays, then
Granny's voice → the viewer opens at
`http://localhost:8000/web/viewer.html?id=sunday-park`.

The family view is at `http://localhost:8000/web/family.html`.

### Using the band companion's recordings

`companion/` (the browser app) records on the band with real GPS and exports
`before-i-forget-memories.json`. `import_companion.py` turns each of its memories
into a `memories/<id>/` folder this pipeline understands, carrying the real
latitude, longitude, accuracy and radius across — the coordinates the keyboard
trigger stands in for.

```bash
python3 import_companion.py ~/Downloads/before-i-forget-memories.json --dry-run
python3 import_companion.py ~/Downloads/before-i-forget-memories.json
```

It derives `location_key` from the place name, so "Stow Lake, Golden Gate Park"
becomes `park` and the demo's `p` key finds it.

**Imports are never approved automatically.** The companion is a self-recording
tool with no family gate; this pipeline has one. An imported memory shows on the
family page as "Waiting for family" and the band stays silent at that place until
someone approves it. The companion also keeps no audio — it streams to Deepgram
and holds only counters — so record her voice separately with
`capture.py 25 --id <id> --text no`.

### If a key is missing

The demo does not have to wait for every API key.

**Granny's voice needs no key.** `capture.py <band> --id <id> --text no` records and
saves `audio.wav` without calling Deepgram. Add the key later to get the transcript too;
the recording is the part the demo plays.

**The narrator line has an offline fallback.** `intro.mp3` is normally ElevenLabs, via
`process.py`. Without that key, macOS can speak the `intro_line` itself:

```bash
LINE=$(python3 -c "import json;print(json.load(open('memories/sunday-park/memory.json'))['intro_line'])")
say -v Samantha -r 145 -o /tmp/intro.aiff "$LINE"
ffmpeg -i /tmp/intro.aiff -codec:a libmp3lame -b:a 128k memories/sunday-park/intro.mp3
```

The committed `intro.mp3` was made this way. Running `process.py` with an ElevenLabs key
overwrites it with the real narrator voice, which sounds considerably warmer.

### About the 3D world

`place_to_world.py` sends the reference photo **and** the `scene_prompt` to World Labs in
one request — the photo fixes the real geometry of the place, the prompt carries
the season and mood from Granny's own words. Generation takes about five minutes
and needs an account with purchased credits.

The API returns Gaussian splats, a GLB mesh, a panorama and a link to the world;
it never returns a video. `place_to_world.py` saves the panorama as `pano.jpg` and the
splat as `world.spz`, and records `world_url` in `memory.json`. The viewer shows that panorama inline and offers
"Walk through this place", which opens the live navigable world in a new tab —
World Labs sends `X-Frame-Options: DENY`, so it cannot be embedded in the page.

Worlds are link-viewable by default; `--private` opts out. Permission can **only** be set
when the world is created — there is no update endpoint — so a private world has to be
regenerated to share it. Other flags: `--dry-run` (find the photo and build the prompt,
send nothing), `--draft` (faster and cheaper), `--place` / `--prompt` (no `memory.json` yet).

## Tech stack

| Piece | What we used |
|---|---|
| Wearable | Vexo Open band — mic, tap/motion sensor, colour light, over Bluetooth |
| Band control | Python + `bleak` |
| Transcription | Deepgram |
| Memory extraction | OpenAI (structured JSON output) |
| Narrator voice | ElevenLabs |
| 3D worlds | World Labs Atlas |
| Web | Static HTML + CSS, no build step, served with `python3 -m http.server` |
| Band companion | `companion/` — a separate browser app (Node, no dependencies) that records on the band with real GPS and watches for a genuine return |

## Safety and privacy

- The band shows a solid blue light whenever the microphone is live.
- Memories default to **unapproved**. Nothing surfaces automatically until a
  family member approves it.
- Memories the model marks `sensitive` (death, illness, conflict, loss) never
  auto-trigger, approved or not.
- Original recordings stay local. `.wav` files and `.env` are git-ignored; no API
  keys live in this repo.
